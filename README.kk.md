Қазақ тіліндегі мәтіндерді тексерудің техникалық қабаты: кодтау мен алфавитті тазалау, қазақ әріптерін қалпына келтіру, линтер, орыс түпнұсқасымен салыстыру
және терминдерді нақты қолданыс бойынша таңдау саясаты. Жоба [redkollegiya](https://github.com/beaverbeard/redkollegiya) үлгісімен жасалған: ол Claude Code үшін
орыс мәтінінің редактурасын үйлестіретін оркестратор, ал бұл жоба қазақ тіліне арналған. Скрипттер табылған ескертулерді redkollegiya-дағы `apply.py` форматында
береді (сөзбе-сөз дәйексөз, ауыстыру, деңгей), ал таласты жағдайда шешімді қазақша оқитын адам қабылдайды.

> **Күйі: 0.x.** Бірінші қабат — скрипттер — дайын. LLM кезеңдері (мағына мен калькалар, машиналық мәтіннің белгілері, емле) және типограф-скрипт әлі жазылған жоқ,
> [даму жоспарын](#даму-жоспары) қараңыз.

Неге қажет екені және не екені туралы толығырақ — [лонгридте](docs/longread.kk.md).

## Қалай жұмыс істейді

```
қазақша мәтін (+ орыс түпнұсқасы)
  → Алтынсарин   kk_clean · kk_restore · kk_lint   гигиена: кодтау, алфавит, сөздік, толтырғыштар
  → Уәлиханов    kk_parity · kk_pairs              түпнұсқамен салыстыру: сандар, күндер, атаулар
  → Шәкәрім      kk_usage · glossary.yaml          терминдер корпус қолданысы бойынша
  → …            жоспарда: Әуезов (мағына), Байтұрсынұлы (норма), Слопотрон-kk (машиналық жазу іздері)
  → apply.py (redkollegiya)                        ескертулерді дәйексөз бойынша мәтінге енгізеді
  → қазақша оқитын адамның шешімі
```

Қағидалар:

- **Бөлек кезеңдер** өз аймақтарымен (`hygiene`, `parity`, `terms`, `norm`, `typography`): гигиена арзан және әр құрастыруда жүреді, адамның шешімі қымбат.
- **Қайта жазушылар жоқ.** Әр кезең дәйексөзі бар ескертулер береді, оларды `apply.py` енгізеді. Түзетуді көзбен тексеру қиын тілде еркін қайта жазу қауіптірек.
- **Таласты жағдай — авторға.** `author_choice` деңгейіндегі ескертулер мәтінге үнсіз енгізілмейді.
- **Гигиена бірінші жүреді:** `apply.py` дәйексөзді әріптеп іздейді, сондықтан «і» орнына латын `i` немесе бөлшектенген `ә` іздеуді бұзады.

## Қабаттар және олардың есімдері

Орыс Редколлегиясында қабаттар өз кәсібінде сөзі өлшем саналатын адамдардың — Чуковскийдің, Аграновскийдің, Розенталь мен Мильчиннің — есімін иеленеді. Мұнда да сол дәстүр, тек қазақ есімдерімен:

| Қабат | Есім | Орыс баламасы | Бұрыннан бар | Жоспарда |
| --- | --- | --- | --- | --- |
| Гигиена және типография | Алтынсарин | Мильчин | `kk_clean`, `kk_restore`, `kk_lint` (H, P01, P03, P04 ережелері) | типограф-скрипт |
| Түпнұсқамен салыстыру | Уәлиханов | Аграновский | `kk_parity`, `kk_pairs` | — |
| Терминдер | Шәкәрім | — | `kk_usage`, глоссарий, T01 және T02 ережелері | модельмен `terms-kk` кезеңі |
| Норма | Байтұрсынұлы | Розенталь | S01, P02, P05, C01 ережелері | 2013 жылғы сөздік, `norm-kk` кезеңі |
| Мағына және тірі сөйлеу | Әуезов | Чуковский | — | `meaning-kk` кезеңі |
| Машиналық жазу іздері | Слопотрон-kk | Слопотрон | — | `ai-markers-kk` кезеңі |

Қабат есімі әр ескертудің `layer` өрісіне жазылады (`altynsarin`, `valikhanov`, `shakarim`, `baitursynov`), ал `kk_lint` пен `kk_parity` жиынтығы қабаттар бойынша ескертулер санын көрсетеді. Болашақ скилдер сондай атты командалар алады (`/altynsarin`, `/shakarim` және т.б.). Неге дәл осы есімдер таңдалғаны — [лонгридте](docs/longread.kk.md#қалай-құрылған).

## Орнату

```bash
git clone https://github.com/bsakhanov/kk-redkollegiya.git
cd kk-redkollegiya
pip install -r requirements.txt        # spylls (Hunspell сөздігінің қозғалтқышы), pyyaml
sh tools/fetch_hunspell_kk.sh          # hunspell-kk сөздігі → data/hunspell/ (репозиторийге кірмейді)
sh tests/run_tests.sh                  # сыртқы мәліметсіз тексеру
```

Python 3.8 немесе одан кейінгі версиясы қажет. `apply.py` скрипті [redkollegiya](https://github.com/beaverbeard/redkollegiya) жобасынан алынады (MIT), жиынтыққа
кірмейді: оған жолды іске қосқанда көрсетесіз. Онымен толық тексеру: `APPLY=/path/to/apply.py sh tests/run_tests.sh`. Әр утилитада `--version` бар.
Толық нұсқаулық — [docs/USAGE.kk.md](docs/USAGE.kk.md).

## Жылдам бастау

```bash
# 1. тазалау (кітаптар, PDF экспорттары); журнал нені және қанша түзеткенін көрсетеді
python3 tools/kk_clean.py books/*.txt -o clean/ --dict data/hunspell/kk_KZ --journal journal.json

# 2. әріптер моделі — таза корпус бойынша; сізде қалады, сыртқа жарияланбайды
python3 tools/kk_restore.py train clean/*.txt -o lm.json.gz

# 3. линтер: ескертулер apply.py форматында
python3 tools/kk_lint.py text.md --dict data/hunspell/kk_KZ --glossary data/glossary.yaml \
        --lm lm.json.gz --json findings.json

# 4. ескертулерді redkollegiya скриптімен енгізу
python3 /path/to/redkollegiya/apply.py --text text.md --findings findings.json \
        --out text_v2.md --report report.json

# орыс түпнұсқасымен салыстыру (абзацтар бос жолмен бөлінеді)
python3 tools/kk_parity.py --ru original.md --kk kazakh.md --glossary data/glossary.yaml

# Joomla тіл бумалары: тек мәндер тексеріледі, толтырғыштар бастапқы файлмен салыстырылады
python3 tools/kk_lint.py kk-KZ.com_x.ini --profile ini --source en-GB.com_x.ini --dict data/hunspell/kk_KZ

# Telegram Desktop экспортынан параллель корпус және екі тілді глоссарийге ұсынылатын жұптар
python3 tools/kk_pairs.py build result.json -o pairs.jsonl
python3 tools/kk_pairs.py align pairs.jsonl -o term_candidates.tsv
```

`kk_lint.py` `blocker` деңгейіндегі ескерту болса (мысалы, Joomla жолында `%s` толтырғышы жоғалса), 2 кодымен аяқталады.
Ереже кодтары — [docs/RULES.kk.md](docs/RULES.kk.md).

## Нені тексердік

Өлшемдер автордың жеке корпустарында жасалды (кітаптар, газеттер, екі тілді корпоративтік арна); мәтіндердің өзі репозиторийге кірмейді.

| Не | Нәтиже |
| --- | --- |
| Қазақ шрифттерінің ескі кодтауын декодтау | романның үш томы PDF-тен: декодтаудан кейін сөздік 77–79% сөзді таниды, бұған дейін мәтін оқылмайтын еді |
| Алмастырушы таңбалар (басқарушы және латын) | PDF кітап: шамамен 760 таңба; 602 сөзді сөздік растады, 154 сөз контекстен шығарылды |
| Қазақ әріптерін қалпына келтіру (`kk_restore`) | модель көрмеген кітаптарда 90,1% сөз бірінші талпыныста қалпына келеді; бір сөзі бүлінген сөйлемдерде — 77% (XX ғасыр прозасы) және 69% (Абай); тиіспеген сөйлемдердің 3,9% және 13,2% бөлігінде жалған ұсыныс бар |
| RU↔KK салыстыру (`kk_parity`) | екі тілді корпоративтік арнаның 1 516 жазба жұбы: 69,0% жұпта алшақтық жоқ, сан мәндерінің өзгеруі — 1,7% жұпта |
| Терминдер саясаты (`kk_usage`) | мысал глоссарийде 25 жұп: қолданыс бойынша 20 шешім және автордың 5 шешімі (2 таласты жағдай және «объект», «концепция», «партнер» халықаралық түрінде қалған 3 ерекшелік) |

## Терминдер саясаты

`kk_usage.py` тапсырыс берушінің корпусына **«корпус қолданысы бірінші; халықаралық сөз — қолданыс болмаған жерде ғана»** ережесін қолданады.
«Халықаралық форма — қазақ формасы» жұбының әрқайсысы үшін қазақша мәтіндегі кездесуді санап, шешім қабылдайды:

| status | Шарт | Не жазылады |
| --- | --- | --- |
| `usage` | бір форма кездесулердің кемінде 70% құрайды, жалпы саны кемінде 10 | сол форма; екіншісі — `avoid` тізіміне |
| `silent` | кездесу 10-нан аз: қолданыс жоқ | халықаралық форма |
| `contested` | үлестер 30–70% аралығында | жазба авторға қалады (әзірше — кездесуі көбірек форма) |
| `status` жоқ | автордың шешімі | `--merge` кезінде қайта жазылмайды |

Шешімдер үнсіз түзету ретінде емес, ұсыныс (`author_choice`) ретінде қолданылады: жеңілген форма тіл иелерінде де кездеседі, ал кейбір кездесулер атаулардың ішінде тұр.
Корпус аудармашылары жұптардың кемінде 85% бөлігінде таңдалған форманы қойған жазбалар үшін `kk_parity` ішінде PR06 тексеруі қосылған. Глоссарийдің өзі —
[data/glossary.yaml](data/glossary.yaml) — мысал; оны өзіңіздікімен ауыстырыңыз.

## Корпустар және құпиялылық

Репозиторийге корпус мәтіндері де, үйретілген модельдер де (`lm.json.gz`) кірмейді: кітаптар мен жарияланымдар қорғауда болуы мүмкін, ал модель — туынды жиіліктер.
`.gitignore` мұндай файлдарды жабады. hunspell-kk сөздігі бөлек жүктеледі.

## Шектеулер

- hunspell-kk сөздігі (OpenOffice жобасы, 2000-жылдардың аяғы, шамамен 54 мың түбір) үміткер сөздерді табады, бірақ төреші емес: шағын таңдамада дұрыс сөздердің 14% белгісіз деп саналды, ал әдейі бүлдірілген 11 сөздің барлығы табылды.
- Әріптерді қалпына келтіру ұсыныстары әдепкіде `suggest` болады; шешімсіз енгізу (`--auto-restore`) тек қазақ әріптерінсіз толық терілген мәтінге ғана қолайлы.
- Латын жазуы өңделмейді: жиынтық қазақ тілінің кирилл жазуына арналған. Латын сөздерге («Sáýir» сияқты) тиіспейді.
- 2013 жылғы емле сөздігі машина оқитын түрде қосылмаған, морфологиялық талдағыш (`apertium-kaz`) тексерілмеген.
- Сөзбен жазылған сандар салыстырылмайды; өлшем бірліктерін қайта есептеу жалған іске қосылуларға әкеледі.
- LLM кезеңдерінің сапасы өлшенбеген: gold-set әлі жоқ. Скрипттер қазақша оқитын адамды алмастырмайды.

## Версиялау

[Семантикалық версиялау](https://semver.org/): `MAJOR.MINOR.PATCH`. `0.x` кезінде командалық жол интерфейстері өзгеруі мүмкін; ескертулер форматы тұрақты және `apply.py` келісімімен сәйкес.
Версия нөмірі `VERSION` файлында тұрады, `--version` опциясымен шығады, `vX.Y.Z` тегтерімен белгіленеді және [CHANGELOG.md](CHANGELOG.md) ішінде сипатталады. Әр релизге `kk-redkollegiya-X.Y.Z.zip` архиві мен оның SHA-256 бақылау сомасы тіркеледі; оны `release-assets` жұмыс процесі жинайды.
