# Типограф `kk_typo` (слой Алтынсарина)

Казахский образец Мильчина: только детерминированные правила, где верный ответ не зависит от смысла фразы. Лучше пропустить, чем сломать.
Юникод-гигиена (двойники, невидимые знаки, схва, старые кодировки) остаётся у `kk_clean`, орфография и пунктуация по смыслу — за слоем
Байтурсынова. Правила решены по обычаю вашего корпуса (около 890 тыс. слов) и по решениям автора от 24.10.2026.

## Запуск

```
python3 tools/kk_typo.py текст.md                 # сводка по правилам
python3 tools/kk_typo.py текст.md --check         # код возврата 1, если есть что править
python3 tools/kk_typo.py текст.md --json f.json   # находки в формате kk_lint, для apply.py
python3 tools/kk_typo.py текст.md --fix -o готово.md
python3 tools/kk_typo.py текст.md --fix --in-place --skip Y02
```

Защищены: фронтматтер, огороженный и встроенный код, адреса и электронная почта, цели markdown-ссылок, теги, упоминания и хештеги,
разделители таблиц. Файлы `.ini` языковых пакетов пропускаются без `--ini`, чтобы не задеть подстановки `%s` и `%1$s`.

## Чего не делает

Орфографию и пунктуацию по смыслу. Дефис перед суффиксом после аббревиатур, цифр и латиницы («ЖШС-ге», «Apple-дің»): там нужна
гармония гласных, это работа правила T01 и слоя Байтурсынова. Десятичную точку → запятую: её не отличить от версий и адресов.
Перенос слов. Правило P01 в `kk_lint` остаётся детектором: типограф чинит то же самое и больше.
