# Gold-set: выборка и разметка

LLM-проходы (`meaning-kk`, `norm-kk`, `terms-kk`, `ai-markers-kk`) нельзя подключать, пока не измерено их качество. Измерить его можно
только на предложениях, которые прочитал носитель языка. Этот документ описывает выборку для такой разметки и порядок работы.

## Что в выборке

240 предложений казахского перевода с русским оригиналом из пар «пост — перевод» (`pairs.jsonl` от `kk_pairs`). Предложения
сопоставлены по порядку там, где в абзацах поровну предложений, числа совпали, а длины сопоставимы. Казахская часть прошла
`kk_clean` и `kk_typo`, чтобы разметчик не видел технического шума. Строки перемешаны; страта каждой строки лежит в отдельном ключе
`goldset_key.csv`, разметчику ключ не даётся.

| страта | строк | зачем |
|---|---|---|
| калька | 70 | есть оборот из списка русизмов: «сонымен қатар», «болып табылады», «жүзеге асыр», «аясында», «атап өт», «қолдау көрсет», «өз кезегінде», «бұл ретте» |
| термин | 41 | в русском предложении есть термин из глоссария: проверка `terms-kk` |
| техническое | 27 | `kk_lint` нашёл дефект (S01, T02, P02): точность самого линтера |
| контроль | 102 | ничего из перечисленного: частота проблем в обычном тексте и доля ложных тревог |

Двадцать четыре строки помечены для второго разметчика.

## Разметка

Файл `goldset.xlsx`: лист «Инструкция» и лист «Разметка». Разметчик заполняет столбцы D–J: проблема («чисто» или «есть проблема»),
основная и дополнительная категория, фрагмент, исправление, уверенность 1–3, комментарий. Категории: калька, порядок слов, управление,
норма, термин, смысл, машинный след, другое. Определения и порядок действий в спорных случаях — на листе «Инструкция».
Время: около 45 секунд на строку, три-четыре часа на лист.

## Контроль качества

Второй носитель размечает только помеченные двадцать четыре строки. Считаем согласие по «проблема / чисто» (каппа Коэна) и по категории.
Порог: каппа не ниже 0,6. Если ниже, определения на листе «Инструкция» переписываются, а спорные строки обсуждаются вдвоём.

## Как будет использоваться

Каждый LLM-проход получает те же предложения без разметки и отдаёт находки с цитатами. Сравниваем с разметкой по каждой категории:
точность (какая доля находок подтверждена), полнота (какая доля размеченных проблем найдена) и доля ложных тревог на страте «контроль».
Подключается проход, у которого точность на спорных категориях не ниже договорённой планки; планку назначает автор набора после первого прогона.

## Чего выборка не покрывает

Машинный след (`ai-markers-kk`): в пресс-материалах он почти не встречается, нужен отдельный набор из человеческих и машинных текстов.
Числа, даты и имена: их проверяет `kk_parity`, разметчику поручено их не искать.

## Воспроизведение

```
python3 tests/bench/goldset_sample.py --pairs pairs.jsonl --out-dir ВЫХОД --dict ПУТЬ/kk_KZ --lm ПУТЬ/lm.json.gz
```
